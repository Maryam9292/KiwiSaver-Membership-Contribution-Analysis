# KiwiSaver-Membership-Contribution-Analysis
Analysis of KiwiSaver membership, contributions, and withdrawal trends using official Inland Revenue NZ data. Built for fintech portfolio using Power BI dashboard + Python EDA
## Project Status
Work in progress — analysis underway.

## Data Source
Inland Revenue New Zealand (IRD) — official KiwiSaver statistics
https://www.ird.govt.nz/about-us/tax-statistics/kiwisaver/datasets

## What This Project Will Cover
- KiwiSaver membership growth trends (2012–2026)
- Contribution behaviour analysis
- Withdrawal pattern analysis (first home, retirement, hardship)
- Scheme provider market share trends

## Tools
Excel (data cleaning) | Power BI (dashboard) | Python (EDA)
